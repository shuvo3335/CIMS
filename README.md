# Contract & Import Management System (CIMS)

Static HTML/CSS/JS implementation of the CIMS design. No build step: open `index.html`, or run `python3 -m http.server`.

- `css/styles.css` – design tokens and shared components
- `js/layout.js` – shared sidebar, top bar and footer
- Pages: `index.html` (upload), `review.html`, `records.html`, `ship-details.html`, `ship-add.html`, `create-pi.html`, `view-pi.html`

Data is sample data held in the page scripts; nothing is persisted.
